# React Basics Demo

This project is a small React practice page built to learn the basics of rendering, state, and event handling.

## What we built

We created a simple shopping-style UI with:
- a product list
- an Add to Cart button for each item
- a cart counter that updates when a product is added
- a live clock using JavaScript time updates
- a cleaner card-style layout with simple modern styling

## Main idea

The page demonstrates a few core React concepts:
- rendering content with JSX
- using state with `React.useState`
- updating the UI after user interaction
- using `useEffect` to run a timer
- looping through data with `.map()`

## Files
